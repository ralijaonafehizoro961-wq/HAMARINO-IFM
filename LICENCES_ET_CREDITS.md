# Composants logiciels et crédits

Ce projet est un assemblage original pour prototypage lors du hackathon FANILO / IFM.
Les modules tiers restent la propriété et sous la licence de leurs auteurs.

- **React Native**, **Expo**, **FastAPI** : frameworks open source (principalement MIT, voir les versions installées et leurs licences).
- **Tesseract OCR** : Apache License 2.0, moteur libre installé séparément sur le système serveur.
- **scikit-learn** : BSD 3-Clause.
- **SQLite** : domaine public.
- **Pillow, httpx, BeautifulSoup, pypdf, pytesseract, feedparser** : consulter leurs déclarations de licence exactes dans les versions installées.
- **OpenAI API** et **Google Fact Check Tools API** : services externes optionnels soumis à leurs conditions, quotas et politiques d'utilisation ; pas des logiciels embarqués dans le ZIP.

Les logos officiels IFM, FANILO, tiers et les articles de presse ne sont **pas** incorporés dans ce ZIP. Les contenus importés restent soumis aux droits de leurs éditeurs. Les données fictives sont explicitement étiquetées « DEMO ».
